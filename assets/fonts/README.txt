Fonte Variável Work Sans
=======================

Este download contém a Work Sans tanto em formato de fonte variável quanto de fonte estática.

A Work Sans é uma fonte variável com o seguinte eixo:
wght

Isso significa que todos os estilos estão contidos nestes arquivos:
WorkSans-VariableFont_wght.ttf
WorkSans-Italic-VariableFont_wght.ttf

Se o seu aplicativo oferecer suporte total a fontes variáveis, agora você pode escolher estilos intermediários
que não estão disponíveis como fontes estáticas. Nem todos os aplicativos oferecem suporte a fontes variáveis ​​e,
nesses casos, você pode usar os arquivos de fonte estáticos da Work Sans:
static/WorkSans-Thin.ttf
static/WorkSans-ExtraLight.ttf
static/WorkSans-Light.ttf
static/WorkSans-Regular.ttf
static/WorkSans-Medium.ttf
static/WorkSans-SemiBold.ttf
static/WorkSans-Bold.ttf
static/WorkSans-ExtraBold.ttf
static/WorkSans-Black.ttf
static/WorkSans-ThinItalic.ttf
static/WorkSans-ExtraLightItalic.ttf
static/WorkSans-LightItalic.ttf
static/WorkSans-Italic.ttf
static/WorkSans-MediumItalic.ttf
static/WorkSans-SemiBoldItalic.ttf
static/WorkSans-BoldItalic.ttf
static/WorkSans-ExtraBoldItalic.ttf
static/WorkSans-BlackItalic.ttf

Como começar
-----------

1. Instale os arquivos de fonte que deseja usar

2. Use a ferramenta de seleção de fontes do seu aplicativo para visualizar a família de fontes e todos os
estilos disponíveis
