## 📌 Sobre o Projeto

O **FAQ - Perguntas Frequentes sobre Projetos Web** é uma aplicação web focada em usabilidade e design limpo. Seu principal objetivo é fornecer aos clientes e usuários respostas rápidas para os questionamentos mais comuns durante o ciclo de vida do desenvolvimento de um site ou sistema.

🚨 **Aviso:** Este projeto encontra-se atualmente **em andamento/desenvolvimento**. Novas funcionalidades, estilos e conteúdos estão sendo implementados continuamente.

## 🚀 Tecnologias Utilizadas

O projeto utiliza as seguintes tecnologias:

- **HTML5:** Estruturação semântica do conteúdo.
- **CSS3:** Estilização, layout responsivo e transições.
- **Git & GitHub:** Controle de versão e hospedagem do código fonte.
- **JavaScript (ES6+):** Lógica e interatividade dinâmica (como a expansão/recolhimento das perguntas no formato accordion).

## 💻 Como Executar o Projeto Localmente

### Pré-requisitos
Você precisará apenas de um navegador web atualizado (Google Chrome, Firefox, Edge, etc.) e do `Git` instalado na sua máquina.

### Passo a passo

1. **Clone o repositório:**
   ```bash
   git clone [https://github.com/leandro-90/web_project_faqs.git](https://github.com/leandro-90/web_project_faqs.git)
   
2. **Acesse o diretório do projeto:**
   ```bash
    cd web_project_faqs

3.  **Abra o projeto no navegador:**

Basta dar um duplo clique no arquivo index.html ou abri-lo diretamente com a extensão Live Server no VS Code.
